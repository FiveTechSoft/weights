Project NanoWSP: Small Transformer via WSPLang (Lookup Testbed)

A complete 2-layer autoregressive Transformer (80,704 parameters) written directly in weight space without stochastic gradient descent. It recalls the pairs written into it (memorization); it is not a language model and no generalization is tested.

🔬 What is NanoWSP?

Instead of merely editing pretrained frontier checkpoints (like MiMo-9B or Qwen3.5-0.8B), NanoWSP was created to test a foundational scientific question: Can an autoregressive Transformer be written, structured, and taught factual behaviors directly through weight algebra without backpropagation?

📐 Micro Architecture

2 Layers ($L=2$), hidden dimension $d_{model}=64$, 2 attention heads ($h=2, d_k=32$), and MLP with GELU ($d_{ff}=128$). Total footprint: 80,704 float32 weights (~320 KB in SafeTensors).

🔤 Clean ASCII Tokenizer

Vocabulary size $V=100$, covering printable ASCII characters 32..126, newlines, and control tokens (<pad>, <bos>, <eos>). Runs at >500 tokens/sec on CPU.

🧬 Direct Weight Programming

Imprints factual sequences, boolean circuits, and syntactic delimiters via Fast Weight Programming outer products and Moore-Penrose projection algebra.

🧩 The Algebraic Discovery: Why Hebb Fails & Moore-Penrose Succeeds

When programming multiple memories with simple outer products, isotropic cone collapse causes fatal interference:

The Cross-Talk Disaster

In an untrained network, activations $k_A$ and $k_B$ for prompts like A-> and B-> cluster tightly in residual space with an empirical cosine similarity of:

cos(k_A, k_B) = (k_A · k_B) / (||k_A|| ||k_B||) = 0.89407 (≈ 89.4% overlap)

Applying naive Hebbian updates $\Delta W = \sum v_i k_i^T$ pollutes memory $A$ with $89.4\%$ of memory $B$'s amplitude, completely erasing the previous association.

The Moore-Penrose Closed-Form Solution

By assembling keys into matrix $X \in \mathbb{R}^{d_{ff} \times M}$ and values into $Y \in \mathbb{R}^{d_{model} \times M}$, the exact weight update that decorrelates all $M$ memories simultaneously without backprop is:

ΔW = Y · X⁺ = Y (Xᵀ X + λ I)⁻¹ Xᵀ

The inverse Gram matrix $(X^T X)^{-1}$ cancels out the mutual cross-talk between all pairs, so all stored pairs are recalled (on the stored keys only).

📊 Empirical Capacity Limits of Weight-Space Programming

What happens when you force too many memories into a single layer? Measured results on NanoWSP ($64 \times 128$ MLP Out):

Pairs ($M$) Gram Condition $\kappa(X)$ Frobenius Norm $\|\Delta W\|_F$ Recall (stored pairs) Unrelated Context Status
$M = 4$ 6.0 25.9 100.0% Pristine (No degradation)
$M = 10$ 34.3 111.9 100.0% Stable
$M = 20$ 324.5 208.1 100.0% Mild dispersion
$M = 40$ 924.6 784.7 100.0% Severe drift (Weyl bounds violated)
$M \ge 50$ > 1300.0 > 1000.0 100.0% General collapse (Overfitting flood)

Scientific Takeaway

In this toy model, unrelated prompts stay intact for small $M$ ($M \le 10$) and degrade as the edit norm grows. That suggests WSP suits small local edits; whether it works for safety patching or loop removal in real LLMs has to be measured with forward passes (see the README, "Status of the results"). However, it cannot replace hierarchical backpropagation across all layers for general-purpose foundation model pre-training.
