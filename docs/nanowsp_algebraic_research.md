# NanoWSP: From corpus to Transformer weights without backpropagation

Research snapshot, 25 November 2026. Experimental code is in [draft PR #10](https://github.com/FiveTechSoft/weights/pull/10), branch experiment/nanowsp-language-core. These are synthetic language models, not a demonstrated natural-language LLM.

## Architecture and scope
All six constructive experiments use the existing KarpathyGPT runtime: two layers, two heads, width 16, FF width 64, vocabulary 4, context 32, no biases or dropout, tied embeddings/output, 6,800 unique parameters. No external lookup during inference, no donor checkpoint and zero optimizer updates for constructed models. The cycle experiment separately trains nine reference models for comparison. All reported passes below are from completed CI logs; artifact contents have not been independently re-evaluated.

## Mathematical foundations
GELU(z)-GELU(-z)=z. With column-vector convention, W1=[I;-I], W2=[A-I,I-A], the residual x+W2 GELU(W1 x)=Ax. This is exact without normalization; pre-LayerNorm requires compensation on the chosen equal-norm representation manifold. Permutation matrices preserve the one-hot manifold. The proof does not imply arbitrary nonlinear operators or arbitrary input states are compiled.

### 1. Cycle and inversion
P maps i to i+1 mod 4. R maps i to -i mod 4; R P R^-1=P^-1. Relabeling tied embedding/output rows conjugates the entire model, not necessarily each learned internal map. Three independent initialization seeds, three training arms (iid, forward cycle, reverse cycle), eight snapshots at 0,1,5,10,20,50,100,500. All reference gates and conjugation gates passed; maximum observed conjugation logit error 0. Both directly compiled models achieved 172/172 deterministic predictions and 4096/4096 arbitrary-history positions each, NLL 2.98e-7. Independently trained inverse weights differ; no proof that training learns the same internal algebra. 72 reference checkpoints and 24 effective QK/VO delta heatmaps generated, not individually inspected.
Source: [cycle_law.py](https://github.com/FiveTechSoft/weights/blob/dc1121481a498460c50bd308dd90cf6cd5e9817e/lab/nanowsp/cycle_law.py); [CI](https://github.com/FiveTechSoft/weights/actions/runs/45501914995); [artifact](https://github.com/FiveTechSoft/weights/actions/runs/45501914995/artifacts/14971625853).

### 3. Contextual retrieval
For y_t=P x_(t-k), use centered token codes and circular position codes, period 64. Rotate query by -2pi k/64; score = 4096 cos(2pi(t-k-j)/64). Causal softmax selects j=t-k, V/O transports token into scratch coordinates, MLP clears original token and position and applies P. Five lags (1,2,4,8,16), three permutations: 15/15 models, 99072/99072 predictions, 6192/6192 exhaustive token-pair probes and 6192/6192 counterfactual probes. Maximum residual error 1.1921e-7, reconstructed selected attention mass 1 in FP32, future-token perturbation error 0, strict reload exact. Zero attention and zero-lag controls near chance (24.15–26.03%). Positions before lag excluded. Finite softmax is not mathematically hard attention; fixed context and positional, not content-addressed retrieval.

### 4. Corpus-only discovery
Count C_k(a,b)=sum_t 1[x_(t-k)=a]1[x_(t+1)=b] on common target positions. Enumerate 17 lags and 24 permutations, maximize matching counts. Accept only unique perfect candidate with coverage and independent validation. 192 hidden recurrences (lags 9..16, all permutations), separate 64/32/64 streams of length64. 192/192 recovered, 479232/479232 held-out predictions, 119808/119808 arbitrary-context probes, 56832/56832 greedy continuation tokens. Six controls rejected (iid, constant, nonpermutation, ambiguous, shuffled, validation violation). This is restricted hypothesis selection, not invention of arbitrary algorithms. Short-lag aliases can be ambiguous.

### 5. Probabilistic compilation
T_k(a,b)=(C_k(a,b)+0.5)/(sum_c C_k(a,c)+2). Select minimum train NLL lag with independent validation margin >=0.02 over other lags and >=0.03 over unigram. Center log T per row, equalize residual norms with opposite scratch coordinates, cancel final LN scale. For row-wise hidden responses H and desired residual Z-E solve H W^T=Z-E (direct solve, not iterative optimization). Tied head produces softmax(log T)=T. 24 hidden distributions, 256/128/128 streams per case, 119808 test positions; 24/24 passes. Mean native NLL .767056257 vs unigram 1.383408649, true .766469570; excess .000586687, conditional KL .000455767, sample TV .018944802; max probability error 9.6792e-8. Both iid controls abstained. All reloads exact. Single-lag conditional models only.
[Code](https://github.com/FiveTechSoft/weights/blob/ff5efea9956481085bea385c4f13e3e4d42bca8e/lab/nanowsp/probability_law.py) | [CI](https://github.com/FiveTechSoft/weights/actions/runs/45550931685) | [artifact](https://github.com/FiveTechSoft/weights/actions/runs/45550931685/artifacts/14994335548).

### 6. Joint dependencies
Count joint contexts for 136 unordered pairs of lags 0..16; smooth and select via train NLL, validate gain >=.10 over best single/unigram and margin >=.03 over other pairs. Two heads retrieve into separate scratch channels; first MLP retains two centered one-hots; second solves 16x16 GELU interpolation for centered log probabilities with equalized norms. Four lag pairs (0,3),(2,7),(5,11),(9,16), modular sum and XOR with .16 symmetric noise; 512/256/256 streams. 8/8 passes, 32768 held-out positions, mean NLL .612154159 vs best single 1.381587646 (55.69% reduction), true .610830676; excess .001323483, sample TV .015162179, max probability error 1.2919e-7, interpolation condition number 7.8301. IID and single-lag controls abstain; all reloads exact. Learns joint tables, not symbolic XOR or systematic generalization to unseen pairs.

## Natural language: the unresolved challenge
The trained reference (4 layers, 4 heads, d256, FF1024, context256, vocab65, 3,230,208 parameters, 5000 AdamW updates) scored sealed Tiny Shakespeare NLL 1.8919 vs 5-gram 2.0816, context gain .1199 (CI .0819–.1521); ICL failed (.125 with examples vs .12 without). [Reference CI](https://github.com/FiveTechSoft/weights/actions/runs/45445464293). Earlier donor-free spectral/random-feature variants did not meet natural-language gates; donor-assisted SVD is not donor-free. In the trained reference, rank4 per head VO retained ~97.2% of the NLL improvement on a trained background, not on initialization ([CI](https://github.com/FiveTechSoft/weights/actions/runs/45477023823)). Direct ridge VO construction failed ([CI](https://github.com/FiveTechSoft/weights/actions/runs/45482139927)); full-model Jacobian correction was locally predictive but failed held-out improvement gates ([CI](https://github.com/FiveTechSoft/weights/actions/runs/45484761081)). No general learning law established. Synthetic results do not overturn these failures.

## Reproduction
Checkout PR #10 or the immutable code commit linked for each experiment; install requirements-dev.txt; run python -u lab/nanowsp/<script>.py --out <new-directory>. See PLAN_CYCLE.md, PLAN_COMPOSITION.md, PLAN_RETRIEVAL.md, PLAN_DISCOVERY.md, PLAN_PROBABILITY.md, PLAN_JOINT.md beside scripts. Outputs include JSON reports and safetensors; CI artifacts expire. Seeds and thresholds are in source/plans. No claim of independent replication.

## Next gate
Replace explicit V^k context tables with shared low-dimensional factors; test held-out combinations and compare equally budgeted baselines. Then use natural text, same corpus split and tokenizer as trained reference, held-out NLL, context corruption, generation and compositional tests. Report failures; beating a single unigram or compiling a table is not evidence of general language learning. Do not use sealed text for model selection.
