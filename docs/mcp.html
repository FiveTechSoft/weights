WSP FastMCP Server

Standard Model Context Protocol gateway enabling AI agents (Claude Desktop, Cursor, OpenCode, Antigravity) to decompile, inspect, and benchmark quantized neural weights safely.

1. Architecture: The Agent Observability Lab

The WSP MCP Server (engine/wsp_mcp_server.py) exposes 13 typed tools over standard I/O (stdio). It decouples autonomous agent reasoning from low-level tensor storage, enforcing process-level safety barriers:

Hard Physical Guardrails: The MCP server enforces a Strict Validation Gate (malformed WSP-Lang code halts instantly before disk access) and a Protected Tensor Policy (writes to token_embd.weight, output.weight, or norm layers are rejected with security_rejection).

2. Client Configuration Snippets

Connect your preferred AI agent environment to the WSP MCP server in seconds:

Claude Desktop (Windows / macOS / Linux)

Add to your claude_desktop_config.json:

{
  "mcpServers": {
    "weights-wsp": {
      "command": "python",
      "args": ["C:/weights/engine/wsp_mcp_server.py"],
      "cwd": "C:/weights"
    }
  }
}

OpenCode (opencode.json)

Already bundled in the repository root:

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "wsp-challenge": {
      "type": "local",
      "command": ["python", "engine/wsp_mcp_server.py"],
      "enabled": true
    }
  }
}

Cursor IDE

Settings → Features → MCP Servers → Add New MCP Server:

  • Name: weights-wsp
  • Type: stdio
  • Command: python engine/wsp_mcp_server.py

4. Live JSON-RPC Example

Agents interact via standard JSON-RPC 2.0 messages over stdin/stdout:

// Client Request:
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "peek_weight",
    "arguments": {
      "gguf": "C:/Users/Anto/llamacpp/mimo-v2.6-distill-qwen-9b-Q6_K.gguf",
      "tensor": "blk.19.attn_output.weight",
      "row": "100",
      "col": "200",
      "top": 3
    }
  }
