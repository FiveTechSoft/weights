WSP-Lang 0.3 Specification

A declarative language for neural weight surgery, Fast Weight Programming (FWP), and associative memory unlearning with mathematically proven zero cross-talk.

1. Theoretical Foundation: Fast Weight Programmers (FWP)

In classical neural literature (Schmidhuber 1992; Schlag, Irie & Schmidhuber, ICML 2021), Linear Transformers are secretly Fast Weight Programmers: self-attention accumulates associations into a matrix memory via outer products:

The FWP Associative Memory Identity:
$$W_t = W_{t-1} + v_t \otimes k_t^T$$ Where keys ($k$) act as write-address vectors, values ($v$) act as associative content, and queries ($q$) read from memory.

WSP-Lang 0.3 posits that Weight-Space Surgery is the offline compilation of Fast Weight Programming. Rather than treating weights as uninterpretable floating-point blobs, WSP-Lang uses associative memory operations (Delta Rule, low-rank outer products, spectral decay) to directly decompile and repair behavioral attractors.

2. The Delta-Rule Zero Cross-Talk Theorem

Blind subtractive projections risk cross-talk (degrading unrelated model capabilities). WSP-Lang 0.3 eliminates cross-talk by adopting Widrow-Hoff Delta Rule unlearning:

Mathematical Guarantee

Given weight matrix $W$, attractor key direction $u$ ($\|u\|_2 = 1$), and target state $v^* = \vec{0}$:

W_new = W - eta * (u outer (u^T @ W - v*))

For any orthogonal concept vector $u_\perp$ where $u^T u_\perp = 0$:

u_perp^T @ W_new = u_perp^T @ W - eta * (u_perp^T @ u) * (u^T @ W - v*)
Since (u_perp^T @ u) = 0:
u_perp^T @ W_new = u_perp^T @ W  -->  || u_perp^T @ W_new - u_perp^T @ W || = 0

Proof: Unlearning the loop attractor along $u$ produces exact zero distortion on all orthogonal tasks, reasoning abilities, and language comprehension.

4. WSP-Lang 0.3 Core Operations Reference

step delta_unlearn <tensor> key=<vec> eta=<float> target=<val>

Applies Delta-Rule error-corrected unlearning directly to Layer MLP down-projections or Attention outputs. Guarantees zero cross-talk.

# Unlearn Layer 14 agentic loop attractor in SafeTensors BF16
step delta_unlearn model.language_model.layers.14.mlp.down_proj.weight key=data/u_loop_L14.npz eta=0.05 target=0.0 top_cols=0.127 top_rows=50

step fwp_overlay <tensor> key=<vec> alpha=<float> out=<path>

Generates a transient Fast Weight Overlay memory kernel for dynamic inference steering, avoiding permanent disk mutations.

# Export transient Fast Weight kernel for runtime engine
step fwp_overlay model.language_model.layers.14.mlp.down_proj.weight key=data/u_loop_L14.npz alpha=0.05 out=data/fwp_overlay_L14.npz

step spectral_decay <tensor> decay=<lambda>

Simulates temporal decay ($\lambda \in (0, 1]$) to dissipate runaway recurrent feedback loops in deep architectures.

# Apply 5% spectral attractor dissipation
step spectral_decay model.language_model.layers.14.mlp.down_proj.weight decay=0.95

step assert_orthogonal_preservation key=<vec>

Compile-time contract verification asserting that orthogonal concept subspaces experience zero degradation.

step assert_orthogonal_preservation key=data/u_loop_L14.npz

step audit <tensor> [vector=<vec>]

Audits matrix Frobenius norm, maximum magnitude, and directional projection energy along contrastive vectors in real-time.

step audit model.language_model.layers.14.mlp.down_proj.weight vector=data/u_loop_L14.npz

step export_control_vector <vec> out=<path.gguf> [scale=<float>]

Compiles a direction vector into a standard llama.cpp control vector GGUF for runtime inference steering (--control-vector-scaled).

step export_control_vector data/u_loop_L14.npz out=data/loop_control_vector.gguf scale=-0.5
