1. The Fast Weight Programming Frontier (ArXiv Literature Review)

Self-attention in Transformers operates fundamentally as a Fast Weight Programmer (FWP) (Schlag, Irie & Schmidhuber, ICML 2021). Rather than treating neural network weights as static black-box tensors, modern representation learning frames weights as dynamic, addressable associative memories governed by outer-product updates:

Key Theoretical Milestones (2021 – 2026)

  • Linear Transformers are Fast Weight Programmers (ICML 2021): Shows that linear self-attention layers write memories via outer products Wt = Wt-1 + vt ⊗ ktT and query them via yt = Wt qt.
  • LEACE: Closed-Form Concept Erasure (NeurIPS 2023 - Belrose et al., arXiv:2306.03819): Proves the existence of a closed-form, least-squares projection that completely eliminates target concept leakage (mutual information $I(X, Y) = 0$) while provably minimizing Frobenius norm distortion on the remaining data manifold.
  • MEMIT / EMMET: Mass Memory Editing (Meng et al. 2023, Gupta et al. 2024): Formulates multi-fact weight synthesis as a covariance-regularized inversion ΔW = (V - W0 K)(KT K + λ C0)-1 KT, preventing spectral collapse under mass association.
  • Gated DeltaNet-2 (Yang et al. 2025, NVIDIA 2026 - arXiv:2412.06464): Decouples erase ($\beta_e$) and write ($\beta_w$) channels in linear attention, demonstrating that orthogonalizing the write subspace from the erased concept guarantees zero cross-contamination.
  • Titans: Test-Time Memory Architecture (Google 2025 - Behrouz et al., arXiv:2501.0663): Introduces a surprisal-driven memory monitor that detects repetitive loops and activates transient memory updates only when prediction surprise exceeds an information-theoretic threshold.

3. Mathematical Formulations & Closed-Form Theorems

1. LEACE Closed-Form Concept Erasure Theorem (Belrose et al. 2023):
Let $u \in \mathbb{R}^d$ be the target direction ($||u||_2 = 1$) and $\Sigma \in \mathbb{R}^{d \times d}$ the feature covariance matrix. The optimal affine projection $P$ minimizing expected Frobenius distortion while achieving exact zero covariance with $u$ is given by:

P = I - (Σ u uT) / (uT Σ u)

Applying $P$ to the neural weight matrix $W$ yields:

ΔW = - (Σ u (uT W)) / (uT Σ u) ==> uT (W + ΔW) = 0.0
2. MEMIT / EMMET Covariance-Regularized Mass Editing (Meng et al. 2023, Gupta et al. 2024):
To insert $M$ associative key-value memories $K \in \mathbb{R}^{d_{in} \times M}, V \in \mathbb{R}^{d_{out} \times M}$ into unquantized matrix $W_0$ without degrading unrelated prompts, the optimal least-squares regularized update is:

ΔW = (V - W0 K) · (KT K + λ C0)-1 · KT

Where $C_0 = \mathbb{E}[k k^T]$ is the unconditioned background covariance and $\lambda > 0$ is the Tikhonov regularization factor, stabilizing the condition number $\kappa(K^T K + \lambda C_0) \ll \infty$.
3. Gated DeltaNet-2 Decoupled Erase & Write (Yang et al. 2025, NVIDIA 2026):
Decoupled channel-wise update with strict orthogonal write projection:

Wt = Wt-1 (I - βe ue ueT) + βw vw kwT
where vw ← vw - (ueT vw) ue (vw ⊥ ue)

Proof of Zero Cross-Contamination: ueT Wt = ueT Wt-1 (1 - βe) + βw (ueT vw) kwT. For $\beta_e = 1.0$ and $v_w \perp u_e$, $u_e^T W_t \equiv 0.0$, guaranteeing that writing new memories never re-awakens the erased attractor.

The Moore-Penrose Pseudo-Inverse Solution

In untrained transformers, activations naturally cluster in a narrow cone ($\cos(x_1, x_2) = 0.894$). Hebbian outer products fail due to cross-talk. WSP-Lang 0.5 applies the Moore-Penrose inverse Gram projection:

ΔW = Y · (XT X)-1 · XT

Delivers 100.0% recall across diverse capabilities (Country capitals: ES:MAD, FR:PAR; Boolean logic: 1&1=1, 1&0=0; Syntax matching: (hello), [item], {block}).

6. WSP-Lang 0.5 Instruction Set Reference

step leace_erase <tensor> vector=<vec> [lambda=<float>]

Applies Belrose et al. (NeurIPS 2023) closed-form least-squares concept erasure. Eliminates target projection to exact machine zero while minimizing Frobenius distortion across feature covariance Σ.

step leace_erase model.language_model.layers.14.mlp.down_proj.weight vector=data/u_loop_L14.npz lambda=0.05

step cov_imprint <tensor> keys=<K.npz> values=<V.npz> [lambda=<float>]

Executes MEMIT / EMMET covariance-regularized mass memory insertion. Regularizes key Gram matrix $(K^T K + \lambda I)^{-1}$ to guarantee well-conditioned weight updates without benchmark degradation.

step cov_imprint model.language_model.layers.14.mlp.down_proj.weight keys=data/K_facts.npz values=data/V_facts.npz lambda=0.1

step decoupled_delta <tensor> erase_vector=<vec> write_key=<vec> write_value=<vec> beta_erase=<float> beta_write=<float>

Implements Gated DeltaNet-2 decoupled channel-wise erase and write linear attention update with orthogonal write projection ($v_{\text{write}} \perp u_{\text{erase}}$).

step decoupled_delta model.language_model.layers.14.mlp.down_proj.weight erase_vector=data/u_loop_L14.npz write_key=data/k_steer.npz write_value=data/v_steer.npz beta_erase=1.0 beta_write=1.5

step surprise_fwp prompt=<text> [threshold=<float>] [metric=<type>]

Titans surprisal test-time memory trigger (Google 2025). Evaluates repetition and entropy metrics to trigger dynamic transient memory overlays when agentic loops emerge.

step surprise_fwp prompt="ls -la app ls -la app ls -la app" threshold=2.0 metric=repetition_rate

step init_architecture [arch_name] [layers=<int>] [d_model=<int>] [heads=<int>] [vocab=<int>]

Synthesizes and initializes a standalone Micro-Transformer architecture from scratch in weight space, creating deterministic Float32 SafeTensors weights ready for weight programming.

step init_architecture NanoWSP layers=2 d_model=64 heads=2 vocab=100

step imprint_batch <tensor> dataset=<type> [M=<int>]

Executes Moore-Penrose pseudo-inverse multi-associative weight synthesis: $\Delta W = Y (X^T X)^{-1} X^T$. Programmatically encodes factual dictionaries, logic gates, and delimiter matching.

step imprint_batch layers.0.mlp_down.weight dataset=associative_memory M=15
