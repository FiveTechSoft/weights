WSP-Lang Specification

A declarative domain-specific language for weight-space programming, surgical neural decompilation, and behavioral steering on quantized large language models.

1. Philosophy & Core Axioms

Traditional deep learning treats neural network weights as an opaque artifact produced exclusively by stochastic gradient descent. In contrast, Weight-Space Programming (WSP) posits that a trained model's weight matrices encode an interpretable, decomposable computer program.

The WSP-Lang Hypothesis: Any behavior, capability, or reasoning pathology in an autoregressive model corresponds to identifiable linear sub-spaces in its projection tensors (FFN down-projections and attention output matrices). By addressing weights directly with declarative primitives, we can inspect, steer, or synthesize capabilities with zero forward passes.

WSP-Lang enforces three foundational design principles:

  • Falsifiable Experiments: Every program declares its target model, objective, safety budget, and holdout threshold.
  • Physical Guardrails: The runtime blocks mutations to critical grounding layers (embeddings, unembedding, RMSNorm scales).
  • Strict Validation Gate: If an AST violates syntax or security constraints, execution is halted immediately before any weights or disk blocks are touched.

2. Formal EBNF Grammar

WSP-Lang uses a clean, Pythonic indentation syntax:

Program          ::= ExperimentHeader Block*
ExperimentHeader ::= "experiment" Identifier ":"
Block            ::= MetadataBlock | BudgetBlock | SemanticBlock | StepsBlock | HoldoutBlock

MetadataBlock    ::= "model:" String
                   | "objective:" String
                   | "hypothesis:" String

BudgetBlock      ::= "budgets:" Newline (Indent Key "=" Value)+

SemanticBlock    ::= "semantic_areas:" Newline (Indent Key "=" Value)+

StepsBlock       ::= "steps:" Newline (Indent StepStatement)+
StepStatement    ::= "step" Operation Arguments*

HoldoutBlock     ::= "holdout:" Newline (Indent Key "=" Value)+

3. Instruction Set Architecture (Primitives)

WSP-Lang 0.1 implements five atomic operations:

step semantic_map [tensor=...] [top=k]

Calculates the functional projection of a tensor against the 10 differential semantic centroids or lists the model-wide taxonomy.

# Rank Layer 14 FFN down-projection against semantic areas
step semantic_map tensor=blk.14.ffn_down.weight top=3

step peek <tensor> [row=r] [col=c] [top=k]

Decompiles a single weight, row, or column into its anatomical role and semantic affinities without modifying weights.

# Inspect Attention Layer 19 (Row 100, Col 200) -> Head #0
step peek blk.19.attn_output.weight row=100 col=200 top=3

step poke <tensor> <row> <col> <value> [out=...]

Surgically modifies a single scalar weight in-place. Automatically re-quantizes only its 256-element Q6_K super-block using canonical quantize_row_q6_k_ref (reconstruction error < 6.2e-6).

# Perturb individual weight cleanly
step poke blk.14.ffn_down.weight 100 4258 0.150

step scale <tensor> col=<neuron_idx> factor=<alpha>

Scales an entire column vector uniformly to amplify or suppress specific behavioral features (Behavioral Steering).

# Scale hostility neuron 4258 in Layer 14 by 2.5x
step scale blk.14.ffn_down.weight col=4258 factor=2.5

step steer <tensor> vector=<u.npz> dose=<alpha>

Applies Covariance-Aligned Steering (Dreaming Technique 16) by adding or subtracting an empirical residual direction vector.

# Subtract repetitive loop direction vector from Layer 17
step steer blk.17.ffn_down.weight vector=data/e6_u_resid.npz dose=-0.85

4. Security Policy & Guardrails

Hardened Defense-in-Depth: WSP-Lang prevents unauthorized model corruption through physical process-level barriers.
Component Policy Rule Enforcement Point
token_embd.weight FORBIDDEN (Embedding matrix protection) Kernel level in wsp.py and MCP server
output.weight FORBIDDEN (LM Unembedding head protection) Blocked before disk write
*.norm.weight FORBIDDEN (RMSNorm scale protection) Pre-execution AST filter
Syntax / Type Errors Strict Validation Gate (Instant execution abort) validate(prog) halts plan
Budget Limits Max norm delta ≤ 0.05, Max modified ≤ 16384 Checked prior to quantization write

5. FastMCP Integration (AI Agents)

WSP-Lang is natively exposed over standard I/O via FastMCP (engine/wsp_mcp_server.py). Autonomous agents can send code blocks in memory and receive structured JSON responses:

// Example: Calling execute_wsplang_code from an AI Agent
{
  "name": "execute_wsplang_code",
  "arguments": {
    "code": "experiment inspect_logic:\n    model: MiMo-2.6\n    steps:\n        step peek blk.19.attn_output.weight row=100 col=200 top=3"
  }
}

6. Concrete Code Walkthrough

Below is a production WSP-Lang program (programs/example_semantic_areas.wspl) mapping semantic areas and decompiling attention, FFN, and SSM recurrent layers:

experiment inspect_semantic_areas:
    model: MiMo-V2.6-Distill-Qwen-9B
    objective: map_semantic_geometry

    semantic_areas:
        mode = comprehensive
        target = math_logic

    steps:
        # 1. Map top semantic areas
        step semantic_map top=3

        # 2. Inspect Attention Layer 19 (Row 100, Col 200)
        step peek blk.19.attn_output.weight row=100 col=200 top=3

        # 3. Inspect FFN Layer 19 (Row 100, Col 500)
        step peek blk.19.ffn_down.weight row=100 col=500 top=3

        # 4. Inspect Recurrent SSM Layer 0
        step peek blk.0.ssm_out.weight row=100 col=200 top=3
