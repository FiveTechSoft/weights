NanoWSP-2: 4-Layer Lookup Testbed

A 4-layer autoregressive Transformer (599,168 parameters) written in weight space via WSP-Lang 0.5 primitives, without gradient descent. It recalls 11/11 imprinted pairs: memorization of the stored items, not generalization. It is not a language model.

1. Architectural Evolution: NanoWSP-1 vs NanoWSP-2

NanoWSP-2 expands the depth and expressive capacity of weight-space programming from a 2-layer associative prototype to a 4-layer lookup testbed:

Specification NanoWSP-1 (v0.4) NanoWSP-2 (v0.5) Architectural Impact
Layers 2 Layers 4 Layers Enables deep hierarchical routing (lexical → arithmetic → relational → syntax)
Model Dimension ($d$) 64 128 4x larger representation manifold; wider orthogonal subspaces
Attention Heads 2 Heads ($d_k=32$) 4 Heads ($d_k=32$) Multi-head specialized routing & decoupled erase/write linear attention
FFN Hidden Dim ($d_{ff}$) 128 256 Higher memory capacity for mass associative synthesis via MEMIT
Vocabulary 100 Chars (Printable ASCII) 256 Bytes (Full 8-bit Byte Space) Supports raw byte streams, code tokens, and arbitrary binary data
Total Parameters 80,704 599,168 7.4x parameter scaling in deterministic Float32 SafeTensors format
Mathematical Framework Moore-Penrose Pseudo-Inverse MEMIT Covariance Regularization + LEACE + Titans Keeps the condition number bounded; the Titans loop stop is a one-prompt demo, not a measured result

3. ¿La Retropropagación es Programable con WSPLang o Realmente No Hace Falta?

¿Es programable? Sí. El descenso de gradiente estocástico (SGD) consiste matemáticamente en una secuencia de actualizaciones de producto exterior de rango-1: ΔW = -η ∑ gi ⊗ xiT. Cualquier paso de retropropagación puede expresarse como una operación de suma externa en WSP-Lang.
¿Realmente hace falta? Para la programación de capacidades, cirugía de pesos y desaprendizaje: a veces no. Argumentos a favor (hipótesis, no demostradas fuera de estos testbeds):

1. Olvido Catastrófico (Catastrophic Forgetting)

El gradiente de retropropagación se dispersa por todos los parámetros sin control ortogonal y puede dañar capacidades previamente aprendidas. En contraste, LEACE y MEMIT proyectan la actualización en el subespacio nulo o minimizan analíticamente la distorsión de Frobenius en la covarianza de fondo. Es una propiedad algebraica de la actualización, no una medida de comportamiento.

2. Eficiencia Computacional: Forma Cerrada vs Iteraciones

SGD requiere miles de iteraciones, backward passes que almacenan todos los mapas de activación en VRAM, y optimizadores como Adam que triplican el consumo de memoria. WSP-Lang resuelve el mínimo de mínimos cuadrados en forma cerrada en un solo paso analítico (20 ms en CPU).

3. Garantía de Extracción Exacta

Al eliminar un atractor nocivo o sesgo, SGD solo reduce la pérdida asintóticamente pero deja energía residual. LEACE garantiza analíticamente que uT (W + ΔW) = 0.0 a precisión de máquina. Es cierto por álgebra: no implica que el concepto desaparezca del comportamiento del modelo, lo cual no se ha medido.

4. ¿Dónde SÍ hace falta Backprop?

Backprop es insustituible para el preentrenamiento fundacional masivo (billones de tokens caóticos de lenguaje natural sin estructura explícita). Una vez que el espacio de representación existe, Weight-Space Programming puede servir para memorización rápida y ediciones localizadas; que sea mejor que el entrenamiento para dirigir comportamiento o razonamiento no está demostrado.

4. Reproducción & Ejecución CLI

NanoWSP-2 puede ser compilado y evaluado directamente desde la terminal:

1. Ejecutar el Showcase Interactivo de Capacidades

python scripts/demo_nanowsp2_capabilities.py

2. Compilar NanoWSP-2 Declarativamente desde Cero vía WSPLang 0.5

python engine/wsplang.py programs/create_nanowsp2.wspl --run

3. Ejecutar la Suite de Tests Automatizados

python -m unittest tests/test_nanowsp2.py
