Every row is one `bench_run` JSON: the served model's sha256, its provenance (when WSP-Lang built it), the suite digest, the decoding and the per-item records are in the file.

**Verdict rule (`bench_compare`, fixed 2026-11-18), for an edit against its base** (the arm's provenance names the base run's model sha, or both runs serve the same file and differ only in extras). *improves* only if (a) on at least one benchmark the arm beats the base with exact two-sided binomial p < 0.05 on both graders, (b) the placebo arm, when given, does not gain significantly on any benchmark / grader (a placebo that harms does not block), (c) when a noise band is given (two runs of the same configuration), |arm − base| ≥ 2 × band on that benchmark, (d) the preservation battery, when both runs carry it, does not fail. *harms* is the symmetric statement. Otherwise *same / not decidable*, with the reasons. Two unrelated models get the paired statistics and the band only, no verdict word. This table counts; the sealed protocol (`lab/probes/sealed/README.md`) decides claims.
