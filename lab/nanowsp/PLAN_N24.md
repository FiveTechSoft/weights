Features: ordered embeddings of last 3 tokens (96 dims) plus deterministic nonlinear random projections of these 96 coordinates, 3 banks of 64 tanh features with fixed seed2424 and standard normal projections scaled by sqrt(96), input multiplied by sqrt(32). Fit-standardize each feature with floor .01; no intercept. Four feature banks of widths96/64/64/64 (288 total). Compare stagewise frozen blocks against one-shot ridge on concatenated features (same 288xV output coefficients and same fixed projections). Each stage fits one bank to current residual Y-P using regularized normal equations, evaluates logit increment gain on selection. Additional additive control fits each bank independently to initial residual, selects gain/lambda on selection independently per bank, sums corrections; same capacity. Evaluate every prefix and final on acceptance; compare shuffled context (half-roll, diagnostic only) with same final stagewise coefficients. Paired block bootstrap128/1000. Gate: final stagewise selection and acceptance gain >=.02 vs base, acceptance CI lower >.01 vs base and >0 vs one-shot, additive, shuffled; at least two nonzero stages and each nonzero stage positive acceptance point gain over previous prefix. Report all choices, prefix losses, CIs and coefficient budgets. No gradient/backprop/donor. Closed-form supervised fitting, not autonomous RSI, not standard Transformer. No compilation until gate passes. Corpus small and same genre; no universal claim.
