# N13 — compile discovered guarded-copy laws into causal Transformer weights
2026-11-25. Local CPU PyTorch 2.10.0 execution of natural_n13.py. 163 models, 162880 parameters each, 2 pre-LN causal attention blocks, 4 heads, d=112, FF=128, tied embedding/readout, vocabulary 16 data symbols + query + reject. No donor weights, optimizer or backward calls. Native forward executes attention, GELU, layer normalization and readout; no symbolic evaluator called during inference.
N11 discovery is rerun on symbols 0..7 for all 99 four-input/two-output guarded-copy laws. N12 search is rerun for 64 four-step chains. Symbolic substitution fuses each chain at compile time into its initial guard and the first two output variables. This is a projection of the composed law, not full four-output execution or layer-by-layer interpretation of the chain.
The first block retrieves the four input tokens using positional attention and computes six pairwise equality flags via symbol-independent GELU conjunctions. The second block checks the complete guard and copies the selected variable; default output is reject. Fixed centered embeddings, anchors and equality-pair norm maintain normalization at the two output positions. Inference greedily generates two output tokens after a query token, appending the first output before predicting the second.
Results: 50184/50184 positive and 46848/46848 negative inputs, all from reserved symbols 8..15. N11 positives exhaustive, up to 256 negative inputs sampled per law. N12 positives and negatives exhaustive within the two-distinct-variable subdomain. 163/163 strict checkpoint reloads, bit-identical logits on one fixed probe per model. Minimum correct-vs-best-other logit margin 99.99695587158203. All parameters assigned algebraically. This is a separate small standalone PyTorch implementation of standard Transformer blocks, not yet the engine/nanogpt_runtime.py integration or the N8 language model. Per-law checkpoints, no shared universal multi-law model. No semantic understanding or open-ended RSI established. Local experiment exploratory, not preregistered; publish CI to reproduce. Repository N12 source returns the inferred warm program explicitly rather than the identical verified ground truth.

Then investigate a closed-loop update of an existing model rather than rebuilding one model per law.
