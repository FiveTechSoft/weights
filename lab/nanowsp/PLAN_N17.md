# N17 — native word-level probability compilation
Reproduce N16 from fixed corpus and its original selection protocol. Compile its selected probability mixture for every vocabulary input into a standard causal Transformer with tied token embeddings and fixed-norm centered log probability output, no optimizer/backward/donor. This is a dense materialization of the mixture, not separate compositional circuits or contextual abstraction: the model is a word-bigram LM. Compare all 2048 conditional distributions in FP32 against float64 reference (max absolute probability error <= 1e-5), acceptance NLL difference <= 1e-5, prefix independence and causal error <=1e-5, exact reload on probes. Record parameters and nonzeros. Also audit a stronger lexical baseline with alpha grid 1..1024 powers of two, tuned only on selection. Report gain and paired 128-token block bootstrap CI on acceptance; require gain >=.02 and lower CI >.01 for predictive gate. Distinguish fidelity from predictive gate. Generate fixed-seed samples (greedy and temperature 1) without claiming coherence. No reserved final 10% access. Same corpus/splits as N16; not fresh external test. No integration with N8 or N15, no claim of semantic comprehension or long context. Dense compilation is an initial correctness baseline, not scalable architecture.
