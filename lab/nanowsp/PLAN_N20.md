# N20 — distant relational retrieval
Use the public-domain GITenberg Through the Looking-Glass ebook 12 (different book from N18; same author). Pin exact Git blob before evaluation, record SHA256. Split body chronologically 70/15/15, N16 tokenizer, vocabulary top 2047 plus unknown. Fit lexical interpolated Kneser-Ney trigram and PPMI/SVD32/k-means128 classes as N18, extend discount grid to .95/.99. Tune discount and last-class interpolation on selection only. Exclude first 128 tokens of each evaluation slice, no cross-split cache. At target t use earlier endpoints j in [t-128,t-9], retrieve successor token j+1 (strictly before t). Compare uniform cache, exact previous-word retrieval (s[j]==s[t-1]), class retrieval (class(s[j])==class(s[t-1])), and random class labels with preserved sizes. For retrieval distribution use (alpha*base + hit)/(alpha+n), alpha grid 4,8,16,32,64,128, selected separately for cache, exact and class on selection. Include alpha infinity (no update). Test whether class retrieval adds value to exact retrieval: candidate starts from tuned exact-retrieval probabilities and applies a second update using only class matches with different lexical identities, then select alpha on selection. Matched control uses random class labels, excludes exact identities, same selected alpha; also random positions matched in count per target (seed fixed). Compare to tuned exact and uniform cache, not just lexical baseline. Gate: class extension gain >=.02 vs exact on selection and acceptance, acceptance paired block-bootstrap lower 95% CI >.01 vs exact and >0 vs uniform cache and both controls. Blocks128, 1000 resamples. Report full metrics, match coverage, conditional gain, all hyperparameters. No tuning acceptance. No neural compilation until gate passes. This tests distant class-conditioned recurrence, not entity resolution, semantic comprehension or general ICL. Same-author new book is not independent domain. No donor or gradient training; external statistical feasibility only.
