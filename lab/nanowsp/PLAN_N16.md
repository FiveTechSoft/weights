# N16 — distributional abstraction on natural text
Goal: test whether automatically inferred word classes improve word prediction beyond lexical bigrams, before compiling native weights.
Corpus: fixed Tiny Shakespeare SHA256 86c4e6aa9db7c042ec79f339dcb96d42b0075e16b8fc2e86bf0ca57e2dc565ed. Tokenize lowercase words and individual punctuation, including newline. Chronological first 70% characters counts, next 10% selection, next 10% acceptance, final 10% excluded because prior experiments reserve part of it. Boundaries tokenized separately. These slices overlap earlier experiments' data; not a fresh external corpus.
Vocabulary top 2047 count tokens, plus unknown. Infer word vectors from left/right neighboring token counts using positive PMI, L2 normalization, deterministic truncated SVD (rank 32), k-means with K=32/64/128, seed 1616, fixed 20 iterations. No semantic labels. Compare lexical smoothed bigram P(w|previous word) vs class-based P(w|class(previous word)), and class-pair factorization P(class(w)|class(previous word))*P(w|class(w)). Use interpolation with lexical baseline; select K, mixture weight and class method on selection only. Compare random permutation of class assignments preserving sizes, same mixture. Report all choices, acceptance full NLL and paired block bootstrap (128 tokens, 1000 replicates), rare and unseen lexical bigram subset. Gate: improvement >=0.02 nats/token on selection and acceptance, acceptance lower 95% CI >0.01 against lexical baseline and >0 against random classes. Also compare against simple frequency-backoff tuning on selection. If failed do not compile. This is external count-based statistical feasibility, not native neural weights, not semantic understanding, no connection to N8 checkpoint yet. SVD/k-means are numerical fitting, not backpropagation; no donor.
