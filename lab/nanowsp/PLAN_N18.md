# N18 — contextual abstraction feasibility
Goal: predictive value of class-conditioned history beyond a strong lexical trigram, without expanding N17. External statistical experiment only.
Use Project Gutenberg Alice's Adventures in Wonderland (ebook 11) as a different corpus from Shakespeare, no semantic annotations. Fetch UTF-8 text, record exact SHA256, remove Gutenberg header/footer using START/END marker lines; fail if absent. Split body chronologically by characters 70/15/15, tokenize separately using N16 tokenizer. Vocabulary top 2047 count tokens plus unknown. Fit all counts and PPMI/SVD32/k-means128 classes on first 70% only, fixed seeds 1818. Selection and acceptance never enter counts. No tuning on acceptance; this corpus is new to the reported N1–N17 experiments, not necessarily universally unseen.
Baseline: interpolated absolute-discount Kneser-Ney lexical trigram with continuation bigram counts (distinct preceding tokens) and continuation unigram counts, positive uniform floor for full vocabulary. Tune shared discount D in {.25,.5,.75,.9} on selection. Also report lexical bigram using same continuation backoff. Class model: conditional next lexical token counts for pair of previous word classes, back off to counts for last class, then lexical unigram with positive floor; smoothing alpha=32. Compare class-history model mixed with baseline, class-last-only mixed with baseline, and shuffled class assignment (same class sizes) with matched mixture weights. Select interpolation weight from {0,.05,.1,.2,.4,.6} on selection for class-history and class-last separately. No acceptance selection. Acceptance: NLL, paired block bootstrap 1000 replicates of contiguous 128-token blocks, unseen lexical trigram subset; compare history mixture vs strong lexical baseline, last-only mixture, shuffled classes. Gate: selection and acceptance gain >=.02 nats/token vs lexical trigram, acceptance CI lower >.01 vs lexical, >0 vs last-only and shuffled. Gate failure is a result, not CI failure. No native compilation unless gate passes. Record exact corpus hash and package versions, counts, all candidates. This is class-conditioned local context, not long-range semantics, N15 integration or unrestricted ICL.
