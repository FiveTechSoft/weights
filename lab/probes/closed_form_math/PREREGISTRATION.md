# Closed-form write of one arithmetic skill: pre-registration (written BEFORE any run)

Question: can a closed-form edit of one MLP down_proj (no gradients) make a small Qwen model answer NEW problems of one arithmetic
skill better, while keeping what it already did well? Writing the answers of the training problems does not count.

Status: design only. Nothing here has been run. `engine/closed_form_write.py` (independent, textbook ridge solve, tested on synthetic
data in tests/test_closed_form_write.py) is the only code. The mechanism is the one published for facts (MEMIT-style); that it
transfers to a SKILL is the hypothesis, and the prior is low: a write fits any targets (test_memorises_shuffled_targets_equally).

## Fixed choices
- Model: Qwen/Qwen3.5-0.8B (Apache-2.0), revision 2fc06364715b967f1860aea9cf38778875588b17. Single file, 1746.9 MB.
- Skill: 2-digit + 2-digit addition with carry, prompt "Q: 47 + 68 = ?\nA:", greedy, answer <= 4 tokens, exact match. Chosen
  because it has a verifiable answer and a rule that generalises; swap for another skill only before looking at results.
- Headroom gate (run first, unpatched only): if base exact match on the 100 held-out problems is >= 80%, the skill has no room and
  the test is void (pick a harder skill, e.g. 3-digit + 3-digit, and restate here before any edit).
- Data: 40 write problems, 100 held-out problems, 100 retention prompts (50 non-math text continuations, 50 subtraction problems).
  All generated by a seeded script; write and held-out sets disjoint on the operand pair. No problem appears in two sets.
- Edit: layer L in {16, 20} (both reported, no selection after seeing results), mlp.down_proj, keys = input of down_proj at the last
  prompt token, value change = the residual that moves the logit of the first answer token to the correct digit, protected keys =
  the 50 text retention prompts' keys, lam = 1e-3. Fixed before running.
- Controls: (1) same write with answers shuffled across the 40 write problems; (2) random update of the same Frobenius norm.

## Criteria (all must hold for "skill write works"; any miss is reported as a miss)
1. Held-out exact match gain over unpatched >= 15 points absolute, exact McNemar test p < 0.05.
2. Held-out gain over the shuffled-answer control >= 10 points (rules out a generic nudge).
3. Retention: >= 95% of the 100 retention prompts give the same greedy output as unpatched.
4. Write problems alone do not count; their accuracy is reported only to show the write took.
Any layer that fails 1-3 is a failed layer. Passing is evidence for that model, skill and layer only.

## Feasibility here (checked, not run)
- Box: 2 CPU, ~1.7 GB RAM free, 15 GB disk. The model file (1.75 GB bf16) does not fit in RAM as a loaded model; it needs a
  layer-streamed forward (embedding matrix alone is ~0.5 GB). A scoring pass of 240 short prompts is minutes on CPU, not hours.
- Blocking decision: downloading the 1.75 GB file (a one-off, pinned, via ByteBudget) and writing a layer-streamed runner for
  Qwen3.5's mixed linear/full attention layers. No spend, no server. Not started: the instruction was no heavy downloads.
- The cached Qwen3.5-9B layers 0-3 cannot run this test: scoring math needs every layer.
